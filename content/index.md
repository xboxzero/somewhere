Welcome — this is **your wiki**, generated with [Quartz](https://quartz.jzhao.xyz), and hosted for free on GitHub Pages.

> [!tip] What you get out of the box
> - Full-text **search** (press `/` or click the search icon)
> - A **graph view** showing how pages link to each other
> - Automatic **backlinks** on every page
> - **Dark / light mode**
> - Folder-based navigation in the left sidebar

## How this wiki works

Every page here is a plain Markdown file living in the `content/` folder of the GitHub repo. To add a page:

1. Create a new `.md` file under `content/`
2. Link to it from another page with `[[relative/path|Display Name]]`
3. Commit and push — the site rebuilds and redeploys automatically

Try the graph view in the sidebar to see how [[guides/getting-started|Getting Started]], [[guides/writing-pages|Writing Pages]], and [[notes/example-note|Example Note]] connect to this page.
